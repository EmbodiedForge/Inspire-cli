# Inspire CLI - AI Documentation

> Quick reference for AI assistants working with the Inspire CLI codebase.

## Project Overview

Inspire CLI is a command-line tool for interacting with the Inspire HPC (High Performance Computing) training platform. It enables users to:
- Submit and manage training jobs on GPU clusters
- Monitor job status and retrieve logs
- Sync code to remote clusters via Git Actions workflows (Gitea/GitHub)
- Launch interactive notebook sessions
- Execute commands on Bridge runners via SSH tunnel or Actions workflows

## Key Commands

```bash
# Configuration
inspire init                    # Create config from detected env vars
inspire init --template         # Create template config.toml
inspire init --global           # Create global config
inspire config show             # Display merged config with sources
inspire config check            # Validate config and test auth

# Jobs
inspire job create --name "train" --resource "4xH200" --command "bash train.sh"
inspire job status <job-id>
inspire job logs <job-id> --follow
inspire job stop <job-id>
inspire job list
inspire job wait <job-id>

# Quick Run (simplified job submission with auto-resource selection)
inspire run "python train.py"                    # 8xH200, auto-select location
inspire run "python train.py" --gpus 4 --type H100
inspire run "python train.py" --watch            # Sync, run, follow logs

# Resources
inspire resources list                # Show GPU availability
inspire resources list --watch        # Watch continuously
inspire resources list --workspace    # Node-level availability

# Code Sync (via Git Actions or SSH tunnel)
inspire sync                    # Push current branch, sync to Bridge
inspire sync --force            # Force sync (discard remote changes)

# Bridge Exec (run commands on Bridge runner)
inspire bridge exec "ls -la"
inspire bridge exec "pip install torch" --no-wait

# Notebooks
inspire notebook list
inspire notebook create --resource 1xH200
inspire notebook stop <instance-id>
inspire notebook ssh <instance-id>

# SSH Tunnel Profiles
inspire tunnel status           # Show current tunnel status
inspire tunnel add <name> --url <proxy-url>
inspire tunnel remove <name>
inspire tunnel list
inspire tunnel ssh-config       # Generate SSH config snippet
```

## Configuration System

### Precedence (lowest to highest)
```
Hardcoded defaults < Global config.toml < Project config.toml < Environment variables
```

### Config File Locations
- **Global**: `~/.config/inspire/config.toml`
- **Project**: `./.inspire/config.toml` (searched by walking up from cwd)

### All Configuration Options

#### Authentication
| Env Var | TOML Key | Description | Scope |
|---------|----------|-------------|-------|
| INSPIRE_USERNAME | auth.username | Platform username | global |
| INSPIRE_PASSWORD | auth.password | Platform password (use env var) | global |

#### API Settings
| Env Var | TOML Key | Description | Default |
|---------|----------|-------------|---------|
| INSPIRE_BASE_URL | api.base_url | API base URL | https://api.example.com |
| INSPIRE_TIMEOUT | api.timeout | API timeout (seconds) | 30 |
| INSPIRE_MAX_RETRIES | api.max_retries | Max retry attempts | 3 |
| INSPIRE_RETRY_DELAY | api.retry_delay | Retry delay (seconds) | 1.0 |
| INSPIRE_SKIP_SSL_VERIFY | api.skip_ssl_verify | Skip SSL verification | false |

## Example config.toml

```toml
# ~/.config/inspire/config.toml (global) or ./.inspire/config.toml (project)

[auth]
username = "your_username"
# password - use INSPIRE_PASSWORD env var for security

[api]
base_url = "https://api.example.com"
timeout = 30

[paths]
target_dir = "/shared/my-project"

[git]
platform = "gitea"  # or "github"

[gitea]
server = "https://codeberg.org"
repo = "myorg/myrepo"
# token - use INSP_GITEA_TOKEN env var

[github]
server = "https://github.com"
repo = "myorg/myrepo"
# token - use INSP_GITHUB_TOKEN or GITHUB_TOKEN env var

[job]
priority = 6
# image = "pytorch:latest"

[notebook]
resource = "1xH200"
```

## Key Code Patterns

### Loading Configuration
```python
from inspire.cli.utils.config import Config, ConfigError

# For commands requiring auth
config = Config.from_env()

# For sync/bridge commands (no platform auth needed)
config = Config.from_env_for_sync()

# With source tracking for display
config, sources = Config.from_files_and_env()
```

### API Client Usage
```python
from inspire.cli.utils.auth import AuthManager

api = AuthManager.get_api(config)  # Returns authenticated InspireAPI
jobs = api.list_tasks()
```

### Git Forge Client (GitHub/Gitea)
```python
from inspire.cli.utils.forge import create_forge_client, trigger_workflow_dispatch

client = create_forge_client(config)  # Returns GiteaClient or GitHubClient
trigger_workflow_dispatch(config, "sync_code.yml", inputs={"branch": "main"})
```

### Click Command Structure
```python
import click
from inspire.cli.context import Context, pass_context

@click.command()
@click.option("--name", required=True)
@pass_context
def my_command(ctx: Context, name: str):
    if ctx.json_output:
        click.echo(json.dumps({"name": name}))
    else:
        click.echo(f"Name: {name}")
```

### Error Handling
```python
from inspire.cli.context import EXIT_CONFIG_ERROR, EXIT_AUTH_ERROR

try:
    config = Config.from_env()
except ConfigError as e:
    click.echo(f"Config error: {e}", err=True)
    sys.exit(EXIT_CONFIG_ERROR)
```

## Exit Codes

| Code | Constant | Meaning |
|------|----------|---------|
| 0 | - | Success |
| 1 | - | General error |
| 10 | EXIT_CONFIG_ERROR | Configuration error |
| 11 | EXIT_AUTH_ERROR | Authentication failed |
| 12 | EXIT_VALIDATION_ERROR | Invalid input |
| 13 | EXIT_API_ERROR | API error |
| 14 | EXIT_TIMEOUT | Timeout |
| 15 | EXIT_LOG_NOT_FOUND | Log not found |
| 16 | EXIT_JOB_NOT_FOUND | Job not found |

## Dependencies

- click: CLI framework
- requests: HTTP client for API calls
- playwright: Browser automation for SSO login
- tomli/tomllib: TOML parsing (tomllib built-in for Python 3.11+)

## Common Tasks for AI Assistants

1. **Adding a new config option**:
   - Add to `inspire/cli/utils/config_schema.py` (ConfigOption)
   - Add field to Config dataclass in `config.py`
   - Add mapping in `_toml_key_to_field()` and `from_files_and_env()`
   - Update llm.txt documentation

2. **Adding a new command**:
   - Create `inspire/cli/commands/mycommand.py`
   - Import and register in `inspire/cli/main.py`
   - Add tests in `tests/test_mycommand.py`

3. **Adding Git forge support**:
   - Modify `inspire/cli/utils/forge.py`
   - Add new client class inheriting from `ForgeClient`
   - Implement `get_auth_header()`, `get_api_base()`, `get_raw_file_url()`, `get_pagination_params()`

4. **Adding tests**:
   - Create `tests/test_myfeature.py`
   - Use Click's `CliRunner` for CLI tests
   - Use `monkeypatch` for mocking
